# Dunia Coding Yasmin

Aplikasi *storytelling* interaktif untuk kajian sarjana — murid mengikuti kisah Yasmin di Dunia Coding dan menyelesaikan misi drag-and-drop untuk konsep **Sequence, Loop, Conditional dan Logic**.

- Buka `index.html` dalam pelayar (mod landskap).
- Semua teks cerita, gambar, audio dan jawapan misi ada dalam `story.js`.
- Data kajian (masa, cubaan, salah, petunjuk, bintang) disimpan dalam pelayar dan boleh dimuat turun sebagai CSV dari menu **📊 Laporan**.
- Buka terus satu misi: `index.html#misi=sequence2` (lihat `BACA SAYA.txt`).
